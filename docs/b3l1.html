Tellen met ongelijkheden

Counting with inequalities

Hoeveel getallen bereiken aantoonbaar 1? Een vraag waar je, anders dan bij het volledige vermoeden, harde vooruitgang op kunt boeken.

How many integers provably reach 1? A question on which, unlike the full conjecture, hard progress is possible.

1De telfunctie en haar exponentThe counting function and its exponent

Definieer \(\pi_1(x)\) als het aantal startwaarden \(\le x\) waarvan de baan 1 bereikt. Het vermoeden zegt \(\pi_1(x) = \lfloor x \rfloor\). Het telprogramma bewijst ondergrenzen van de vorm:

Define \(\pi_1(x)\) as the number of starting values \(\le x\) whose orbit reaches 1. The conjecture says \(\pi_1(x) = \lfloor x \rfloor\). The counting programme proves lower bounds of the form:

$$\pi_1(x) \;\ge\; x^{\gamma} \qquad (x \text{ groot / large})$$

Elke verhoging van \(\gamma\) is echte, meetbare vooruitgang: \(\gamma = 1\) zou "vrijwel alle getallen" betekenen (op teltermen na). De exponent is dus een voortgangsmeter voor het hele probleem · en die meter beweegt, zoals subject 3 laat zien.

Every increase of \(\gamma\) is real, measurable progress: \(\gamma = 1\) would mean "essentially all integers" (up to counting terms). The exponent is thus a progress gauge for the whole problem · and the gauge moves, as subject 3 shows.

2Het idee: zelfconsistent tellen in de boomThe idea: self-consistent counting in the tree

Herinner de omgekeerde boom uit les 1.2: vanuit 1 groeien voorgangers via ×2 en (soms) via (m−1)/3. Tel per grootte-schijf en per restklasse hoeveel boomknopen er zijn. De boomregels vertalen zich dan in ongelijkheden tussen die tellingen: het aantal knopen in klasse \(i\) op schaal \(x\) is minstens een gewogen combinatie van aantallen op schaal \(x/2\) en \(x/3\) in gerelateerde klassen.

Recall the inverse tree of lesson 1.2: from 1, predecessors grow via ×2 and (sometimes) via (m−1)/3. Count tree nodes per size range and per residue class. The tree rules then translate into inequalities between those counts: the number of nodes in class \(i\) at scale \(x\) is at least a weighted combination of counts at scales \(x/2\) and \(x/3\) in related classes.

Difference inequalities: tellingen op schaal x worden van onderaf gevoed door tellingen op kleinere schalen. Vind je gewichten waarvoor dit stelsel zichzelf met groeifactor \(x^{\gamma}\) in stand houdt, dan is \(\pi_1(x) \ge x^{\gamma}\) bewezen.
Difference inequalities: counts at scale x are fed from below by counts at smaller scales. If you find weights for which this system sustains itself with growth factor \(x^{\gamma}\), then \(\pi_1(x) \ge x^{\gamma}\) is proved.

De kunst is dus een zelfconsistente gewichtenset te vinden. Hoe fijner je de restklassen kiest (mod 9, mod 27, … mod \(3^k\)), hoe meer structuur je vangt en hoe hoger de haalbare \(\gamma\) · tegen exponentieel groeiende rekenkosten. Dat is het speelveld van les 3.2.

The art is to find a self-consistent set of weights. The finer the residue classes (mod 9, mod 27, … mod \(3^k\)), the more structure you capture and the higher the achievable \(\gamma\) · at exponentially growing computational cost. That is the playing field of lesson 3.2.

Welke ondergrens is bewezen voor de Collatz-telfunctie?What lower bound is proven for the Collatz counting function?

De telfunctie π₁(x), het aantal startwaarden ≤ x waarvan de baan 1 bereikt, voldoet aan π₁(x) ≥ x^0.9184 voor grote x. Dit record uit 2026 is verkregen met exacte certificaten tot diepte k=21, goed voor 3,5 miljard geverifieerde constraints. Het volledige vermoeden zou overeenkomen met exponent γ = 1.

The counting function π₁(x), the number of starting values ≤ x whose orbit reaches 1, satisfies π₁(x) ≥ x^0.9184 for large x. This 2026 record was obtained with exact certificates up to depth k=21, comprising 3.5 billion verified constraints. The full conjecture would correspond to exponent γ = 1.

Wie bewezen de eerdere ondergrenzen voor de Collatz-telfunctie?Who proved the earlier lower bounds for the Collatz counting function?

Crandall gaf in 1979 de eerste expliciete ondergrens met γ ≈ 0.05. Krasikov haalde 0.43 in 1989 met difference inequalities mod 9, Applegate en Lagarias 0.81 in 1995 (computerondersteund, mod 3⁹), en Krasikov en Lagarias 0.84 in 2003 (verfijnd stelsel, mod 3¹¹).

Crandall gave the first explicit lower bound in 1979 with γ ≈ 0.05. Krasikov reached 0.43 in 1989 using difference inequalities mod 9, Applegate and Lagarias proved 0.81 in 1995 (computer-assisted, mod 3⁹), and Krasikov and Lagarias 0.84 in 2003 (refined system, mod 3¹¹).

Hoe leveren difference inequalities een ondergrens voor Collatz?How do difference inequalities give a lower bound for Collatz?

In de omgekeerde Collatz-boom groeien voorgangers via ×2 en soms via (m−1)/3, dus tellingen op schaal x worden van onderaf gevoed door tellingen op schaal x/2 en x/3 in gerelateerde restklassen. Vind je een zelfconsistente gewichtenset waarvoor dit stelsel zichzelf met groeifactor x^γ in stand houdt, dan is π₁(x) ≥ x^γ bewezen.

In the inverse Collatz tree, predecessors grow via ×2 and sometimes via (m−1)/3, so counts at scale x are fed from below by counts at scales x/2 and x/3 in related residue classes. If you find a self-consistent set of weights for which this system sustains itself with growth factor x^γ, then π₁(x) ≥ x^γ is proved.

Waarom verbetert het verfijnen van restklassen de exponent γ?Why does refining residue classes improve the exponent γ?

Hoe fijner de restklassen (mod 9, mod 27, tot mod 3^k), hoe meer boomstructuur de ongelijkheden vangen en hoe hoger de haalbare γ. De prijs is exponentieel groeiende rekenkost: het huidige record γ = 0.9184 gebruikt diepte k=21 met 3,5 miljard constraints.

The finer the residue classes (mod 9, mod 27, up to mod 3^k), the more tree structure the inequalities capture and the higher the achievable γ. The price is exponentially growing computational cost: the current record γ = 0.9184 uses depth k=21 with 3.5 billion constraints.
